# 🎂 Lahari Reddy — Ammulu Birthday Website

A colorful, crazy, animated birthday website made by **Raju** for **Lahari Reddy (Ammulu)**.

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. No server or installation is required.

## Included
- 9 uploaded photos
- 3D-style tilt hero card
- Animated confetti
- Birthday cake / balloons / party emojis
- Brother's personal birthday message
- Photo gallery with hover effects
- Responsive mobile layout
- "Maximum Madness" party button
- Birthday date: **19 September 2026**

The page uses Google Fonts when internet is available; the rest of the site works locally.
